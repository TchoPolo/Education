# Complice de Classe — kit de déploiement

**Signature :** Tous vos outils, un seul complice.

## Fichiers

- `complice-de-classe-icon-1024.png` : master iOS / App Store
- `complice-de-classe-icon-512.png` : Android / Google Play / PWA
- `complice-de-classe-icon-192.png` : PWA
- `apple-touch-icon.png` : raccourci iPhone et iPad
- `favicon.ico` : navigateur web
- `complice-de-classe-logo-horizontal.png` : signature principale sur fond clair ou transparent

## Palette

- Bleu encre : `#20233F`
- Corail : `#FF6B61`
- Jaune étincelle : `#FFC94A`
- Menthe : `#5ED6B3`

## Usage

- L’icône carrée est fournie sans coins arrondis : iOS et Android appliquent eux-mêmes leur masque.
- Le logo horizontal doit conserver une zone de respiration autour du symbole et du nom.
- Ne pas étirer, recolorer ou modifier les proportions.

Avant une commercialisation publique, compléter la vérification préliminaire par une recherche d’antériorité auprès de l’INPI.
